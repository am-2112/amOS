# **Overview**
## What will amOS be?
At its core, amOS will have a monolithic exokernel, provide a simple command line shell; abstractions along with further functionality will be provided in library operating systems (libOSes) that can be added later on.

Developing further from an exokernel should be easier since additional features can be steadily added through libOSes. Also, this can theoretically allow things like running different operating system applications on one machine, and having greater performance for native applications.
